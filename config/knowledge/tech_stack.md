# Engineering & Automation Stack

## Content Distribution & Automation Architecture
* **Automation Core:** Multi-agent content engines built with Python, hosted on GitHub with GitHub Actions for automated execution.
* **AI & Development Tooling:** Developed and maintained using GitHub Copilot Pro, Python, Node/npm packages, and API integrations (e.g., Blogger API).
* **Data & Logic Systems:** Data logic layout on Base44 and custom distribution workflows.

## Development Standards
* **Version Control & CI/CD:** Git-first workflow strictly on GitHub, leveraging GitHub Actions workflows for continuous integration and automated tasks.
* **Lean Execution:** Minimal external dependencies, clean folder structures, and automated JSON/YAML config parsing.
